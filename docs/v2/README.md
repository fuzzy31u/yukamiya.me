# V2 review checkpoint

The five discovery documents in this directory describe the initial architectural checkpoint. They are retained as the design rationale; implemented details now live in `v2/README.md` and `v2/.automation/portfolio-curator/README.md`.

This PR introduces an isolated Astro implementation. Netlify Deploy Previews use `v2/` with Node 24 and noindex; production retains the Gatsby build, Node 14 setting and Gatsby plugin. Do not merge as a production-cutover decision. Preview configuration follows Netlify's documented [deploy contexts](https://docs.netlify.com/build/configure-builds/file-based-configuration/). The Gatsby plugin is installed in Netlify's UI, so it cannot be restricted using context-specific plugin blocks. Keep its global installation and set its supported `NETLIFY_SKIP_GATSBY_BUILD_PLUGIN=true` only in the deploy-preview environment; no shared Netlify UI change is needed.

The legacy plugin version 1.0.3 ignores that environment setting and generates a Gatsby function inside the Astro project. `v2/package.json` therefore pins plugin 3.8.4 as a temporary build-only dependency so Netlify resolves the skip-capable version from the preview base directory. The root Gatsby dependencies are unchanged. Remove this compatibility dependency when the Gatsby plugin is removed at cutover; its transitive dependency audit findings must be reviewed before any production migration.

Implemented: English/Japanese portfolio, three sourced case studies, preserved activity archive and book-review URL, static metadata, deterministic checks, and shadow-mode authored-article curation. Remaining: hosted preview QA, Lighthouse/accessibility audits, broader source adapters, GitHub publishing activation, old service-worker retirement, and reviewed cutover/rollback.
